把经验写在别人的平台上，最大的风险不是没人看，而是**哪天平台不在了，你的积累也就没了**。

所以我做的第一件事，是给自己建一个完全受控的地方。

## 写在别人平台上，你其实什么都没留下

- 内容排序由算法决定，认真写的东西可能一辈子没人看到；
- 平台改版、关停、封号，你无法申诉，也搬不走；
- 数据不归你，导出格式经常是残缺的。

而一个静态站点不一样：**它是一堆 Markdown 文件**。哪怕十年后 GitHub Pages 没了，文件还在你硬盘上，换个地方重新托管只要十分钟。

## 一个网站真正解决的问题

我把它拆成四件事，这也是本站的四个栏目：

1. **工作经验**——把项目里的判断和取舍写清楚。写的过程会暴露自己没想明白的地方。
2. **产品展示**——让别人快速知道我在做什么，这比简历有用。
3. **学习笔记**——用自己的话重写一遍，才算真的学会。
4. **随笔感悟**——对生活的理解是会变的，记下来才能看到自己的变化。

## 为什么用 Astro + GitHub Pages

| 关注点 | 这套方案 |
| --- | --- |
| 成本 | 0 元。静态托管，没有服务器 |
| 速度 | 纯 HTML，打开即显示 |
| 数据归属 | Markdown 文件在自己硬盘 |
| 维护成本 | push 一次，自动发布 |
| 迁移成本 | 换托管商只改一条命令 |

这套组合最大的好处是**没有黑盒**：出问题时你能看到每一层发生了什么。

## 下一步

先写起来，别先折腾主题。网站好不好看不重要，**三个月后有没有十篇内容才重要**。

> 写作的复利来自持续，而不是来自某一篇的完美。
